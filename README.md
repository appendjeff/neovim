# Jeff's LazyVim config
I've been using vim since a colleague showed me its power in 2015. I moved on to neovim in 2026 after reading Dusy Phillips book about LazyVim (see below).


#### About LazyVim
Checkout [LazyVim](https://github.com/LazyVim/LazyVim) to get yourself setup.
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.
